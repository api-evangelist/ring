# Ring

> Ring is an Amazon home-security company (video doorbells, cameras, alarm systems, and the
> Ring Protect subscription). In 2026 Ring launched the Ring Developer platform and Ring
> Appstore, letting certified partners build video-powered apps against the Ring Partner API
> (Amazon Vision API / AVA) — a JSON:API-format REST API secured with OAuth 2.0 one-way
> account linking. Ring also publishes a remote MCP server so AI coding assistants can query
> the documentation while building integrations.

## Overview

- Base URL: https://api.amazonvision.com
- Auth: OAuth 2.0 authorization-code + refresh; token endpoint https://oauth.ring.com/oauth/token; Bearer tokens (expires_in 14400s); server-to-server only.
- Format: JSON:API. Content types application/json, application/sdp (live video), binary (media downloads).
- Rate limit: 100 TPS per partner client_id; 429 with Retry-After.
- Pagination: JSON:API cursor (page[cursor], links.next), fixed page size 25.

## Endpoints (v1)

- GET /v1/devices — list devices (?include=status,capabilities,location,configurations)
- GET /v1/devices/{device_id} — get a device
- GET /v1/devices/{device_id}/status — online/offline status
- GET /v1/devices/{device_id}/capabilities — codecs, motion, image enhancements
- GET /v1/devices/{device_id}/location — coarse location for compliance
- GET /v1/devices/{device_id}/configurations — motion/privacy zones, image settings
- GET /v1/history/devices/{device_id}/events — event history
- POST /v1/devices/{device_id}/media/streaming/whep/sessions — start WebRTC/WHEP live video
- DELETE /v1/devices/{device_id}/media/streaming/whep/sessions/{session_id} — close session
- POST /v1/devices/{device_id}/media/video/download — download media clip
- POST /v1/devices/{device_id}/media/image/download — download image snapshot
- GET /v1/users/me — authenticated user's Account ID
- GET/POST /v1/accounts/me/app-integrations — manage app integrations
- GET /v1/accounts/me/subscriptions — query subscriptions

## Webhooks

- v1.1 payload, HMAC-verified, POST to a partner endpoint; deduplicate on meta.request_id.
- Events: motion_detected, button_press, device_added, device_removed, device_online, device_offline, app_integration_added, app_integration_removed, subscription_activated, subscription_deactivated.
